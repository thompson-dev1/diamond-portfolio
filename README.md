# Diamond Portfolio — Salamatu Adamu

Personal portfolio and showcase for Salamatu Adamu — fashion & beauty model, IT professional (BSc Information Technology Management), and web developer.

## Tech Stack

- Next.js
- Tailwind CSS
- Framer Motion
- GSAP
- TypeScript

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the portfolio.

## Building for Production

```bash
npm run build
```
